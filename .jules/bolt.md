## 2026-07-01 - Date Formatting Bottleneck in Logging Libraries
**Learning:** Formatting ISO 8601 strings on every log event is a major bottleneck in logging libraries across multiple languages (Node.js, Python, Go). Since log libraries typically only need millisecond precision (or even if they need more, many log aggregators group them closely anyway, though here `Date.now()` gives ms), caching the formatted ISO string within the same millisecond significantly improves throughput. For example, in Node.js, `new Date().toISOString()` is an order of magnitude slower than pulling a cached string when log volume is high within the same millisecond.
**Action:** Always check if a timestamp is being dynamically string-formatted on every hot path. Consider caching the string representation of time rounded to the nearest millisecond to improve throughput.
